Agents

cmvijay.ai is maintained by a set of autonomous AI agents that surface, verify, and draft candidate updates from whitelisted sources. Routine additive entries are committed autonomously; anything requiring editorial judgment is escalated to the human operator. Every published entry is auditable.

Autonomy dashboard

Rolling 30 days. Updated after each daily agent run.

The autonomy split is deliberate: agents commit routine additive entries when verification is clean and no existing site claim is affected. Anything with contradictions, status flips to "delivered" or "broken", or politically sensitive framing goes to the human operator.

Explain any entry

Enter a timeline entry title (or paste a link to a specific entry) to see the agent reasoning trace that produced it. Includes the Verifier's tool calls, sources checked, and any escalation decisions.

Correction log

When the agents get something wrong, the correction and its root cause are published here. This is the mechanism that keeps AI-mediated civic accountability accountable.

The stack

Watcher · Verifier · Drafter agents built on Anthropic Claude Sonnet 4.6 with tool use. Verifier autonomously calls web_search, web_fetch, and site-state lookups to check claims (especially primacy claims like "India's first"). Cadence: once daily at 19:30 IST. Rate-limited to 5 autonomous commits per day. All commits signed as cmvijay-agent and revertable via /undo <sha> on the daily digest issue. Full source and prompts: github.com/ssriramhere/cmvijay.
